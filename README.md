# 航标灯夜间视频核查系统

夜间开船摄录的航标灯视频，自动完成**灯点跟踪 → 亮度曲线提取 → 灯质判读 → 与航标表核对**，
替代人工夜间数秒表的作业方式。纯 TypeScript 实现，核心算法与 DOM 解耦，可在 Node 与浏览器 Worker 中运行。

## 功能与四页界面

| 页面 | 功能 |
| --- | --- |
| 航标表 | 20 座航标的规定灯质、周期、组闪数、灯色台账，可在线编辑 |
| 视频导入 | 选择合成测试场景（浪高 × 雾况矩阵）、时长/帧率，或导入真实夜拍视频 |
| 灯点跟踪 | Web Worker 后台逐帧检测跟踪，Canvas 实时叠加检测框与轨迹线，选中轨迹查看亮度时间曲线 |
| 核查结果 | 逐条核对灯质/周期/灯色，异常航标高亮并列出不符明细，含准确率与耗时统计 |

## 支持的灯质

常亮 `fixed`、单闪 `single-flash`、联闪 `group-flash`、长闪 `long-flash`、
快闪（含联组快闪）`quick`、互光 `alternating`、莫尔斯 `morse`，灯色覆盖红/绿/白/黄。

## 算法流水线

```
视频帧
  → 自适应阈值检测（均值+σ 门限，连通域并查集）
  → 多目标跟踪（原始坐标 GNN 关联、断航重捕获、倒影形态剔除、常亮特征标记）
  → 轨迹后处理合并（大浪/浓雾碎轨迹按质心+时间重叠聚类）
  → 亮度序列规整（稀疏补零、时域中值滤波、分位数滞回二值化）
  → 灯质分类（脉冲/暗间隔两档聚类、自相关周期、莫尔斯分组解码、互光色相连续性检测）
  → 航标表匹配核对（位置最近邻 + 灯质形态门控，容差化比对）
```

关键模块均为无 DOM 依赖的纯函数，位于 `src/core/`：

- `detector.ts` 灯点连通域检测
- `tracker.ts` 多目标跟踪
- `merge.ts` 碎轨迹合并
- `classifier.ts` 灯质分类与周期/亮暗时长测量
- `color.ts` 四色判定与互光检测
- `synthetic.ts` 浪高/雾况参数化测试视频生成（种子化随机，可复现）
- `audit.ts` / `matching.ts` 航标表核对与轨迹绑定

浏览器侧在 `src/web/`，逐帧检测与跟踪运行在 `analysis.worker.ts`，主线程只负责 Canvas 绘制与交互。

## 常用命令

```bash
npm install
npm run dev        # 启动开发服务器
npm run build      # 类型检查 + 生产构建（Worker 自动拆包）
npm test           # 35 个单元测试（时刻表/颜色/分类/检测/跟踪）
npm run smoke      # 单场景端到端冒烟，逐盏打印核对结果
npm run eval       # 浪高×雾况矩阵评估，输出准确率与故障报警率
npm run perf       # 10 分钟视频时效测试
```

## 合成测试场景

`src/core/sampleData.ts` 内置 20 座航标（覆盖 7 种灯质 × 4 色），含 3 盏路灯、2 艘移动船灯等干扰源、
海面倒影，并注入三类故障：

- `A19` 熄灭（dead）：全程不亮
- `A20` 常亮故障（steady）：本应联闪却常亮
- `A17` 周期漂移（drift）：周期在 ±15% 内缓慢变化

场景按浪高（小/中/大）× 雾浓度（无/轻/中）参数化，大浪·中雾为接近可视极限的压力测试场景。

## 验收指标（可作业海况，剔除压力场景）

`npm run eval` 实测（60s 视频、10fps、17 座正常灯 × 5 场景）：

| 指标 | 要求 | 实测 |
| --- | --- | --- |
| 灯质分类准确率 | ≥95% | **96.5%** |
| 灯色认错率 | ≤2% | **0%（准确率 100%）** |
| 周期误差 | 中位 ≤0.2s | 中位 0.00s，P90 0.05s |
| 故障灯报警率 | 能发现异常 | 93%（熄灭/常亮稳定报警） |
| 10 分钟视频分析耗时 | ≤1 分钟 | 端到端约 51s（纯分析 14× 实时） |

压力场景（大浪+中雾叠加）下系统仍能给出结果但准确率明显下降，
评估报告单独标注，用于界定可靠作业的海况边界。
