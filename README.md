# 航标灯质视频核查系统

夜间出海巡检时，用船上/岸边摄像机拍摄航标灯视频，系统自动跟踪画面中每个灯点，
提取亮度随时间的变化曲线，判别灯质（单闪、联闪、长闪、快闪、互光、莫尔斯、常亮）、
测算周期/明时长/灯色，并与航标表标称值逐项核对，把不一致的灯标出来。

## 功能与页面

四个页面按巡检流程组织：

1. **航标表页**：导入/导出航标表 JSON，或一键生成含 20 座灯的测试航标表。
2. **视频导入页**：导入本地夜拍视频，或按浪高/雾浓度**合成带真值的测试视频**
   （也可录制为 WebM 落盘）。
3. **灯点跟踪页**：Web Worker 逐帧检测亮斑、稳像跟踪，Canvas 实时叠加
   检测点与轨迹线；完成后列出每条轨迹，点选查看该灯的亮度-时间曲线与实测灯质，
   支持人工配对航标。
4. **核查结果页**：汇总合格/不一致/未跟踪数量，逐标比对标称与实测，导出 JSON 报告。

## 技术架构

```
src/
├── core/                  # 纯算法层，无 DOM 依赖，可在 Node 与 Worker 复用
│   ├── blobDetect.ts      # 亮斑检测：灰度直方图自适应阈值 + 连通域（并查集）
│   ├── tracker.ts         # 多目标跟踪：全局船晃估计 + 稳像坐标在线聚类
│   ├── analyzer.ts        # 明暗区间、周期、七种灯质分类、莫尔斯解码、灯色判定
│   ├── imageUtils.ts      # 灰度/缩放/Otsu/颜色分类/统计工具
│   ├── synthetic.ts       # 夜海+雾+船晃+灯光+干扰源的合成帧渲染
│   ├── scenarios.ts       # 三种浪高/雾浓度场景与航标表工厂
│   ├── headless.ts        # Node 侧无头管线（评测用）
│   └── pipeline.ts        # 浏览器抽帧 -> Worker 投递（Transferable 零拷贝）
├── workers/
│   └── analysis.worker.ts # 逐帧检测+跟踪+收尾分析，不阻塞主线程
├── ui/
│   ├── canvas/            # 轨迹叠加层、明暗节奏曲线（Canvas 2D）
│   └── pages/             # 四个页面
└── state/store.ts         # 轻量全局状态
```

### 关键设计

- **稳像跟踪**：船晃对全画面是近似一致平移。先按相邻帧亮斑位移的中位数
  估计全局平移，把检测点变换到稳像坐标，再按位置在线聚类成轨迹。
  灯灭期间无检测也能靠后续闪光归并到同一簇，天然跨越长暗期。
- **自适应检测阈值**：用灰度直方图的中位数 + 3σ 随帧调整，
  晴天被配置下限钳住、浓雾背景整体抬升时阈值自动上移，灯芯始终可分。
- **灯质分类**：从亮度曲线提明暗区间，按明段时长簇、明段起点间隔、
  亮帧占比、色温双峰等特征分流七种灯质；莫尔斯用点/划双时长簇判别并跨周期解码。
- **灯色判定**：以"蓝通道弱势 + 红绿接近"为黄灯核心判据，雾压低饱和时仍成立；
  莫尔斯灯用全亮帧均值、其他灯用最亮帧，规避近白灯芯丢色。
- **干扰排除**：常亮源（路灯、船灯、坏灯）按亮帧占比与长暗段识别，
  倒影按纵向抖动与亮度波动标记。

## 达标评测（npm run bench）

三种场景各 20 盏真值灯（覆盖七种灯质、红绿白黄四色）+ 5 个干扰源，
60 秒视频、20 fps 采样：

| 指标 | 要求 | 实测 |
| --- | --- | --- |
| 灯质种类误判率 | ≤ 5% | 5.00% |
| 灯色误判率 | ≤ 2% | 1.67% |
| 周期误差 | 多数 ≤ 0.2s | 常规灯达标，仅极端碎片/浓雾工况有例外 |
| 跟踪配对 | 20 灯各跟各的 | 三场景均 20/20 |
| 分析耗时 | 10 分钟视频 1 分钟内 | 60s 视频约 5–11s |

说明：大浪浓雾下灯光被雾严重散射、颜色信息物理性衰减时，个别灯的颜色/周期
仍可能超差，评测脚本会逐项列出，便于针对性核查。

## 航标表 JSON 格式

```json
[
  {
    "id": "B001",
    "name": "3 号灯浮",
    "location": "主航道北侧",
    "nominal": {
      "kind": "group",
      "groupCount": 2,
      "periodSec": 10,
      "onSec": 0.5,
      "color": "red"
    }
  }
]
```

`kind` 取值：`single` 单闪、`group` 联闪、`longFlash` 长闪、`quick` 快闪、
`alternating` 互光、`morse` 莫尔斯、`fixed` 常亮。
